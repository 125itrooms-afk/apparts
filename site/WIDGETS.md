# Виджеты Smart Booking на w125.ru

Код сайта - копия w125.ru (совпадает с боевым на 14.10.2026) с встроенными виджетами.

## Что изменено в `index.html`

1. Перед `</body>` - настройки под сайт (`window.V125_WIDGETS_CONFIG`) и скрипт `widgets/v125-widgets.js`.
2. Под формой бронирования - ссылка «Подобрать номер за 1 минуту» (`data-v125-open="quiz"` открывает квиз; без скрипта ведёт к #rooms). Добавлен перевод EN/ZH.
3. Вопрос FAQ «Можно снять апартаменты надолго?» - `data-v125-action="long_stay_interest"`: раскрытие запускает сценарий «Длительное проживание».

В `.htaccess` добавлены типы и кэш для видео и скрипта. Остальной код сайта не тронут.

## Как виджеты уживаются с сайтом

- Shadow DOM: стили сайта и виджетов не пересекаются.
- Шрифты Onest и Unbounded и цвета (тёмно-зелёный + золото) взяты с сайта.
- Нижняя мобильная панель «Выбрать даты» (`.mbar`) и cookie-плашка (`#ck`) не перекрываются: кнопки поднимаются над ними и опускаются, когда плашку закрыли.
- Мобильная версия включается с той же ширины, что у сайта (760 px).
- Модуль Bnovo не трогаем: кнопки «Забронировать» в виджетах ведут в тот же модуль с датами и гостями.
- Персонализация меняет заголовок и подзаголовок первого экрана только для найденного сегмента (например, `utm_campaign=corp...`) и только в русской версии.
- Цели виджетов в Метрике называются `v125_*` и не пересекаются с целями сайта (`book_click`, `phone_click`, `max_click` и др.).

## Режимы

- **Без `data-api`** (как сейчас) - предпросмотр: всё работает, но заявки никуда не уходят, гость видит подпись «Предпросмотр». **На боевой сайт в таком виде не выкладывать.**
- **С `data-api="https://w125.ru/api"`** - боевой режим: настройки и заявки идут через сервер (см. `widgets/docs/LAUNCH.md`).

## Обновить скрипт

```bash
cd widgets && npm install && npm run build:site   # пересобирает site/widgets/*
```

## Известные ограничения

- Виджеты только на русском; при переключении сайта на EN/中文 они остаются русскими.
- Видео - слайд-шоу из фото сайта. Замените на настоящий ролик: `widgets.video.src` в настройках.
- Уведомления о бронированиях молчат, пока не подключён Bnovo (так и задумано: без фактов - без утверждений).
