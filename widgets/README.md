# Варшавка 125 | Smart Booking Widgets

Интерактивный прототип системы виджетов для сайта апарт-отеля «Варшавка 125» и панели управления к ней.
Механики по мотивам Envybox, дизайн и код свои.

**Это честный прототип.** Серверной части нет, интеграции не подключены. Всё, что выглядит как данные
(история заявок, аналитика, A/B-результаты, наличие Bnovo), помечено DEMO. Звонки не совершаются,
в Bitrix24 и Метрику ничего не отправляется: панель показывает, *что именно* ушло бы.

## Запуск

```bash
cd widgets
npm install
npm run dev            # прототип: http://localhost:5173
npm run build          # проверка типов + сборка в dist/
npm run build:demo     # демо одним HTML-файлом: dist-demo/index.html
npm run build:embed    # скрипт для сайта: dist-embed/v125-widgets.js (~80 КБ gzip)
```

## Что можно сделать в демо

Переключатель вверху: **«Сайт гостя»** / **«Панель управления»**.

Сайт гостя:
- мультикнопка → обратный звонок (маска +7, выбор времени, согласие на ПД), чат, Telegram, MAX, бронирование;
- чат с консультантом: даты («с 12 по 15 ноября», «12.11-15.11», «на выходные»), гости, цель, контакты → заявка;
- квиз из 5 шагов с прогрессом, «назад» и продолжением после перезагрузки;
- генератор заявок: уход с сайта, долгое изучение цен, интерес к длительному проживанию, корпоративная реклама;
- персонализация главной по источнику (симулятор справа: Директ, корпоративная РК, ВК, повторный визит);
- видеоприветствие, уведомления о бронированиях (только при включённых DEMO-данных Bnovo);
- режим «Телефон» - мобильная версия всех виджетов;
- журнал событий справа - какие цели ушли бы в Яндекс Метрику.

Панель управления (переключатель «Войти как» меняет роль и права):
- Главная, Виджеты (редактор с живым предпросмотром), Заявки (статусы, ответственный, история, payload Bitrix24),
  Чаты (ответ гостю как менеджер, база знаний), Сценарии, A/B-тесты, Аналитика (формулы по значку ⓘ),
  Интеграции, Сотрудники (матрица прав), Настройки (бренд, контакты, часы, SLA, код установки).

Состояние демо хранится в localStorage браузера. Сброс: Настройки → «Сбросить демо».

## Структура

```
src/
  core/        логика без UI: типы, стор, правила показа, A/B, чат-движок, заявки и антиспам,
               интеграции (Bnovo/Bitrix24/Метрика), формулы KPI, DEMO-данные
  widgets/     клиентские виджеты (общие для демо и embed)
  site/        демо-сайт отеля и симулятор посетителя
  admin/       панель управления
  ui/          кнопки, поля, графики
  embed.tsx    точка входа скрипта для сайта (Shadow DOM)
```

## Ограничения прототипа

| Что | В прототипе | В проде |
|---|---|---|
| Заявки | localStorage браузера | PostgreSQL + Bitrix24 |
| ИИ-консультант | правила + база знаний, без LLM | LLM с инструментами, ответы только из базы знаний и Bnovo |
| Наличие и цены | нет, либо DEMO-генератор | Bnovo API через сервер |
| Уведомления о бронях | только DEMO-факты | агрегаты из Bnovo по порогам |
| Телефония | не звонит | callback API провайдера |
| Напоминания менеджерам | таймер во вкладке | серверная очередь, Bitrix24/MAX/Telegram |
| Роли | переключатель | вход, сессии, RBAC на сервере |
| Аналитика | синтетика за 90 дней + ваши тестовые заявки | события + Метрика + Bnovo |
| Фото | сгенерированные иллюстрации | фотографии объекта |
